# Quick Task: Support Non-Root User Setup and Rootless Mode in Docker

## Goal
Update Docker container configuration, tests, and documentation to run with a dedicated non-root user (`livesync` UID/GID 1000:1000) by default, ensure `/vault`, `/data`, and home directory permissions allow arbitrary UID/GID execution for rootless Docker environments, and add integration tests verifying non-root container behavior.

## Tasks

### Task 1: Update Dockerfile for Non-Root and Rootless Support
- Create `livesync` user and group (UID 1000, GID 1000) with home directory `/home/livesync`.
- Prepare `/vault`, `/data`, and `/home/livesync` directories owned by `livesync:livesync` with permissive `chmod -R 777` permissions to allow arbitrary UID/GID execution in rootless Docker / Podman / user-namespace environments.
- Set `ENV HOME=/home/livesync`.
- Declare `USER livesync`.

### Task 2: Update Integration Tests
- Update `tests/integration/docker-daemon.test.ts`:
  - Build the Docker test image in `beforeAll` before running tests.
  - Verify container image inspect reports `User: 'livesync'`.
  - Add tests validating execution under default non-root user (`livesync` / UID 1000) and arbitrary UID (`--user 1001:1001`).

### Task 3: Update Documentation
- Update `README.md` Docker section with guidance on rootless Docker, custom UID/GID mappings, and compose `user:` configuration.
