<objective>
Implement the LiveSync encoding, chunk-first push adapter, and logical deletion writer for bidirectional synchronization.

Purpose: Remote writes must strictly adhere to the LiveSync protocol: new or updated files must extend a proven base revision, chunks must be uploaded and confirmed before the note metadata doc is written (preventing broken/half-written note documents), and file deletions must be represented as logical deletion revisions rather than destructive HTTP DELETE calls.
Output: `src/livesync/push-adapter.ts`, `src/livesync/deletion-writer.ts`, and unit tests.
</objective>

  <name>Task 1: LiveSync PushAdapter with chunk-first sequencing</name>
  <files>src/livesync/push-adapter.ts, tests/unit/push-adapter.test.ts</files>
  <behavior>
    - `PushAdapter` accepts file path, file bytes (Uint8Array), optional base revision (`baseRev`), and negotiated settings (chunk size, encryption passphrase, E2EE algorithm V1/V2, path obfuscation, PBKDF2 salt).
    - It splits content into chunks, generates deterministic chunk IDs (`h:...` or `e:...`), encrypts chunks if configured, and checks remote chunk existence.
    - It uploads any missing chunk documents via PUT with verified 201/200 OK responses.
    - Only after all referenced chunk documents are stored, it generates the note metadata document (with `_id`, `_rev: baseRev` if editing, `type: 'newnote' | 'plain'`, `children: [chunkIds]`, `size`, `mtime`, `ctime`), encrypts metadata if configured, and writes the note document.
    - If any chunk write fails, the note document write is aborted immediately, preventing orphaned metadata references (SYNC-03).
    - If note document PUT returns a CouchDB 409 conflict, the error is caught and wrapped as a structured conflict result.
  </behavior>

  <behavior>
    - `DeletionWriter` accepts target path, proven base revision (`baseRev`), and negotiated settings.
    - It constructs a LiveSync logical deletion document `{ _id: docId, _rev: baseRev, deleted: true, type: 'notes', mtime: Date.now(), ctime: ... }`.
