## Phase Goal

**As a** vault operator, **I want** the pull coordinator to execute quarantine deletions safely, record pull checkpoints upon successful completion, and provide clear diagnostic summaries for both modifications and idempotent no-op runs, **so that** vault synchronization is fully observable, recoverable, and crash-resilient.

<objective>
Integrate the pull execution pipeline with recoverable quarantine, checkpointing, and rich diagnostics:
1. Update `applyVerifiedPull` to execute `quarantine-delete` via `quarantineVaultFile` and `deleteProvenance`.
2. Persist pull checkpoints in `CheckpointRepository` on clean completion.
3. Update `runPullCommand` to inspect local files, load provenance, and pass full state to `buildRecoverablePullPlan`.
4. Enhance `formatPullHumanReport` and `formatPullJsonLinesReport` to report `created`, `quarantined`, `noop`, `skipped`, and `blocked` counts.

Purpose: Connect domain planning, filesystem quarantine, and SQLite checkpoints into the complete CLI pull command.
Output: End-to-end pull coordinator with comprehensive diagnostics and unit tests.
</objective>
