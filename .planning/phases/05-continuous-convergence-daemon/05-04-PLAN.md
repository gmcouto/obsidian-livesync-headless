  <name>Task 1: Implement ShutdownHandler for SIGINT/SIGTERM coordination and state persistence</name>
  <files>src/daemon/shutdown-handler.ts, tests/unit/shutdown-handler.test.ts</files>
  <behavior>
    - `ShutdownHandler` listens for `SIGINT` and `SIGTERM` on `process`.
    - Coordinates orderly shutdown steps:
      1. Logs shutdown initiation message.
      2. Closes intake streams (`FsWatcher.close()`, `ChangesConsumer.close()`).
      3. Calls `FileWorkerPool.drain(10000)` to wait for in-flight tasks (with a 10s deadline).
      4. Flushes and commits sequence checkpoints and provenance to SQLite.
      5. Closes SQLite database connection.
      6. Invokes optional cleanup callback or exits process with exit code 0.
    - If a second signal is received during shutdown, immediately forces exit.
  </behavior>
