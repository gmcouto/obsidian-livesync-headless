## Phase Goal

**As a** vault operator, **I want to** dry-run and then materialize verified LiveSync remote files into an empty or dedicated vault, **so that** I can recover vault content without granting any remote write capability and without destroying unproven local or remote data.

<objective>
Deliver the production-quality tracer: `pull --dry-run` admits a remote database (adopting path/case/dynamic-iteration tweaks), inventories documents over GET, decodes one unencrypted legacy `notes` leaf, prints a pull plan, and proves zero CouchDB/vault/provenance mutation.

Purpose: Prove the pull architecture end-to-end on the simplest recoverable path before expanding encryption, chunks, conflicts, and apply.
Output: Runnable `pull --dry-run` CLI path with CONFLICT exit code 8 reserved and negotiation unblocked for real LiveSync vaults.
</objective>
