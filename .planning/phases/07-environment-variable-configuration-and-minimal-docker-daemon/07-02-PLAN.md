<threats>
- T-07-03: Excessive Attack Surface / Bloated Image — Runtime container including Node.js source tree, npm build tools, compilers, or temporary keys. (Mitigation: Multi-stage build discards all build tools, npm packages, and intermediate artifacts; runtime base is minimal `debian:bookworm-slim` containing only the binary, `ca-certificates`, and `tzdata`).
- T-07-04: Host Filesystem State Collision / Overwrite — Unconfigured container running as root writing state database directly into the vault root or unmapped host paths. (Mitigation: Container explicitly configures isolated volumes `/vault` and `/data`, setting default `LIVESYNC_DATABASE_PATH=/data/.state.db` distinct from `/vault`).
</threats>
</threat_model>

<task type="auto" tdd="true">
  <name>Task 1: Create .dockerignore and multi-stage Dockerfile with daemon defaults</name>
  <files>Dockerfile, .dockerignore</files>
  <behavior>
    - `.dockerignore` excludes `.git`, `node_modules`, `dist`, `.planning`, `tests`, `coverage`, `.env*`, and temporary files from Docker context.
    - `Dockerfile`:
      - **Stage 1 (`builder`)**: `node:24-bookworm-slim`
        - Sets `WORKDIR /app`.
        - Copies `package.json` and `package-lock.json*`, runs `npm ci`.
        - Copies `tsconfig.json`, `src/`, `scripts/`.
        - Executes `npm run build:sea` to generate standalone native binary at `dist/obsidian-livesync-headless`.
      - **Stage 2 (`runner`)**: `debian:bookworm-slim`
        - Installs `ca-certificates` and `tzdata`, removes apt cache (`rm -rf /var/lib/apt/lists/*`).
        - Copies binary from `builder` stage: `/app/dist/obsidian-livesync-headless` -> `/usr/local/bin/obsidian-livesync-headless`.
        - Ensures executable permission `chmod +x /usr/local/bin/obsidian-livesync-headless`.
        - Creates `/vault` and `/data` mount directories.
        - Sets default environment variables:
          - `ENV LIVESYNC_VAULT_PATH=/vault`
          - `ENV LIVESYNC_DATABASE_PATH=/data/.state.db`
        - Declares `VOLUME ["/vault", "/data"]`.
        - Configures `ENTRYPOINT ["/usr/local/bin/obsidian-livesync-headless"]`.
        - Configures `CMD ["daemon"]`.
  </behavior>
