<task type="auto">
  <name>Task 1: Create GitHub Actions multi-arch Docker publish workflow</name>
  <files>.github/workflows/docker-publish.yml</files>
  <behavior>
    - Workflow triggers on:
      - `release: types: [published]`
      - `workflow_dispatch`
    - Grants minimal permissions: `contents: read`, `packages: write`.
    - Steps:
      - `actions/checkout@v4`
      - `docker/setup-qemu-action@v3`
      - `docker/setup-buildx-action@v3`
      - `docker/login-action@v3` with `registry: ghcr.io`, `username: ${{ github.actor }}`, `password: ${{ secrets.GITHUB_TOKEN }}`
      - `docker/metadata-action@v5` generating tags for:
        - `type=semver,pattern={{version}}`
        - `type=semver,pattern={{major}}.{{minor}}`
        - `type=raw,value=latest,enable=${{ !github.event.release.prerelease }}`
      - `docker/build-push-action@v6` with:
        - `context: .`
        - `platforms: linux/amd64,linux/arm64`
        - `push: ${{ github.event_name != 'pull_request' }}`
        - `tags: ${{ steps.meta.outputs.tags }}`
        - `labels: ${{ steps.meta.outputs.labels }}`
        - `cache-from: type=gha`
        - `cache-to: type=gha,mode=max`
  </behavior>
  <action>
Create `.github/workflows/docker-publish.yml` with the verified GitHub Actions workflow configuration.
  </action>
  <verify>
    <automated>test -f .github/workflows/docker-publish.yml</automated>
    <fails_when>file does not exist</fails_when>
  </verify>
  <done>
`.github/workflows/docker-publish.yml` is created and properly configured for multi-arch container publishing to GHCR.
  </done>
