<threats>
- T-06-03: Missing Runtime Dependency Failure — Packaged binary fails at runtime on target systems lacking Node.js, npm, or specific global libraries due to unresolved dynamic imports. (Mitigation: esbuild bundles all source code and transitive dependencies into a single CommonJS file; integration test executes binary in a scrubbed environment with PATH='/usr/bin:/bin' and no node in PATH).
- T-06-04: Process Injection / Binary Tampering — Alteration of the SEA blob or sentinel fuse during packaging. (Mitigation: Use exact sentinel fuse `NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2` with postject and verify binary checksum and signature).
</threats>

<task type="auto" tdd="true">
  <name>Task 2: Implement SEA packaging script with esbuild and postject</name>
  <files>scripts/build-sea.mjs, package.json</files>
  <behavior>
    - Add `esbuild` (^0.28.2) and `postject` (1.0.0-alpha.6) to `devDependencies` in `package.json`.
    - Add `"build:sea": "node scripts/build-sea.mjs"` to `scripts` in `package.json`.
    - `scripts/build-sea.mjs` orchestrates the build:
      1. Bundles `src/bin.ts` into `dist/bundle.cjs` with `esbuild` (`platform: 'node'`, `target: 'node24'`, `format: 'cjs'`, `bundle: true`, `external: ['node:*']`).
      2. Generates `dist/sea-config.json` with `disableExperimentalSEAWarning: true` and runs `node --experimental-sea-config dist/sea-config.json` to create `dist/sea-prep.blob`.
      3. Copies host Node binary (`process.execPath`) to `dist/obsidian-livesync-headless`.
      4. Injects `dist/sea-prep.blob` into `dist/obsidian-livesync-headless` using `postject` with sentinel fuse `NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2`.
      5. Sets permissions `chmod 0o755` on the generated executable.
  </behavior>
  <action>
Install dependencies, create `scripts/build-sea.mjs`, and update `package.json`. Test the build script locally.
  </action>
  <verify>
    <automated>npm run build:sea && test -x dist/obsidian-livesync-headless</automated>
    <fails_when>non-zero exit or binary missing</fails_when>
  </verify>
  <done>
`npm run build:sea` successfully produces the standalone executable `dist/obsidian-livesync-headless`.
  </done>
