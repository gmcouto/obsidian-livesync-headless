<threats>
- T-06-05: Format Divergence / Schema Desynchronization — Headless client writes metadata or chunk structures that official Obsidian LiveSync clients fail to parse or reconstruct. (Mitigation: Integration tests use Commonlib 0.1.21 splitChunks, chunkSha256, and serialization directly to verify byte-for-byte fidelity).
- T-06-06: Silent Winner Data Overwrite — Headless client blindly adopts CouchDB deterministic winning revision during concurrent multi-client edits, discarding upstream edits. (Mitigation: Sync coordinator queries all open leaf revisions via open_revs=all and halts with CONFLICT when ambiguous leaves exist).
</threats>
